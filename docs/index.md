# Skills · 中文 AI 技能库

**面向中文用户的 AI agent 技能导航站。不用懂英文、不用懂代码,挑好技能,复制一句话,你的 AI 助手就帮你装好了。**

聚合优质 skill、中文讲解、一键安装、来源可信——解决中文用户"找不到、装不上、不敢装"三大难题。

## 这个网站是干嘛的

- **发现**:把散落在 GitHub 各处的英文 skill 整理成中文目录,分类、搜索,看得懂
- **安装**:不用手敲命令。每个技能都有一段"给 AI 的话",复制发给你的智能体(Claude Code、Reasonix、Cursor…),它自己会装
- **信任**:只收正版开源(MIT 等宽松许可证)技能,标注原作者和出处,放心用
