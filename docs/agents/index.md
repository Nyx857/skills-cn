# 专家角色

让 AI **扮演**一个专业角色来帮你干活——不是"技能"(教 AI 会做某件事),而是**人设**(让 AI 自称并像一位专家那样思考和行动)。装上后,你的 AI 助手就能变身小红书运营、抖音操盘手等。
