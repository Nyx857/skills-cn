# 关于本站

SkillsCN(中文 AI 技能库)是一个**面向中文用户的 AI agent skills 导航平台**。我们帮你解决三个问题:

## 我们解决什么

1. **找不到**:中文/双语 skill 散落在 GitHub、公众号、知乎,没有统一索引
2. **装不上**:Claude Code、Codex、Cursor、Gemini CLI 等工具的 skills 目录各不相同,手动 `cp -r` 极易出错
3. **不敢装**:第三方 skill 本质是向 agent 注入指令,质量与安全需要背书

## 我们的原则

- **只收录宽松许可证**的 skill(MIT / Apache-2.0 等),无许可证的一律不收
- **中文导读自己写**,不是机器翻译原文
- **不重新托管原文件**,安装命令一律指向原仓库
- 每个页面固定展示:原作者、原仓库、许可证、版权声明

## 收录流程

1. 脚本检查许可证(无 LICENSE 不收)
2. 人工核对许可证类型与授权范围
3. 撰写中文导读(自己写的摘要,非翻译)
4. 登记分类、适用工具、安装命令

## 合规声明

本站收录的 skill 版权归各自原作者所有。我们依据 MIT / Apache-2.0 等开源许可证的授权条款提供中文导读与索引,并完整保留原始版权信息。如您认为某条目侵犯权益,请联系我们下架。

> 本站为独立开源项目,与 Claude、Anthropic、OpenClaw 等品牌无隶属关系,站名不使用任何注册商标。
