# test-driven-development

<div class="skill-meta">
  <span class="badge license">MIT</span>
  <span class="badge category">开发流程</span>
  <span class="source">来源: <a href="https://github.com/obra/superpowers" target="_blank" rel="noopener">https://github.com/obra/superpowers</a></span>
</div>

一种被验证的靠谱开发方法:先写测试,再写功能。

**大白话**:就像考试先看到答案再答题。AI 先写"这段代码应该输出什么"的检查规则(测试),然后写代码让这些规则通过。这样改坏东西能立刻发现。

**举个例**:做计算器,先规定"1+1 必须等于 2""5×3 必须等于 15",然后才写计算逻辑,每改一次都自动验证一遍。

适合:任何让 AI 写功能代码的场景,尤其是你怕它"看着对其实错"的时候。

## 安装(超简单,一句话搞定)

**不用敲任何命令。** 复制下面这句话,发给你的 AI 助手(Claude Code、Reasonix、Cursor、Codex 等都行),它会自己帮你装好:

<div class="ask-box">
  <pre class="ask-phrase">帮我安装 test-driven-development 这个技能,它来自 https://github.com/obra/superpowers ,装好告诉我是干什么的</pre>

</div>
